# 应用图标

`source.png` 是用户选定的绿色几何 A 原图，使用内置图像生成工具生成。构建时用 Tauri icon 命令生成 PNG、ICNS 和 ICO，同一图标用于 macOS 关于窗口与安装包。

设计方向：错位的斜向层叠，以深绿主体、青柠点缀和浅鼠尾草底色形成抽象 A，使用扁平几何造型，不使用对话框。

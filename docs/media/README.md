# 项目演示媒体

这里存放项目 README 使用的横版宣传片、封面与高清截图。

- `agent-sessions-landscape.mp4`：30 秒，1920 × 1080，60 fps，H.264 / AAC，支持边加载边播放。
- `promo-cover.png`：横版视频封面，1920 × 1080。
- `conversation-dark.png`、`trajectory-dark.png`、`conversation-light.png`、`settings-dark.png`：当前应用界面的 2560 × 1440 原始截图。
- `logo.svg`：由项目应用图标的矢量图层组合而成。

README 的在线播放使用 GitHub 视频附件，可在[项目首页](../../README.md#30-秒认识-agent-sessions)的折叠区域展开播放器；仓库保留同一份 MP4，供下载与离线查看。

所有会话、项目和执行结果均为虚构演示数据。截图来自最新前端和独立的演示后台，不包含个人历史、认证信息或真实项目内容。视频中的接力场景是流程演示，目标 Agent 需能读取同机文件。

横版视频沿用原竖版的 30 秒时间轴、深绿与青柠配色、原创配乐与音效，按 16:9 重新编排画面，并更新为当前应用截图。配乐由 XSXB-Band 工程制作；视频字体使用得意黑、Noto Sans SC 和 JetBrains Mono（SIL Open Font License）。此目录不分发字体文件。

截图中出现的第三方 Agent 名称与图标用于标识本地会话来源；相关图标许可见 [来源图标许可](../../frontend/src/assets/agents/LICENSE)。部分界面样式的来源与许可见 [DeepSeek Harness MIT 许可](../../frontend/public/harness-license.txt)。

本目录的演示媒体是文档资源，不是应用运行所需的构建产物。应用安装包、数据库和个人会话不纳入版本控制。

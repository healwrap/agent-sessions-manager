# 项目展示媒体

README 以会话管理和账号管理为核心介绍 Agent Sessions，Skill 安装管理作为辅助工作区。展示图标使用当前蓝色应用图标；现有视频继续作为早期会话功能演示。

## 当前主视觉

- `account-workspace.jpg`：2026-10-29 从当前前端截取的账号管理界面，1280 × 720。展示 Claude / Codex 账号列表、独立浏览器与 Claude App 切换、专用代理、语言和时区配置。
- `logo.png`：直接复用 `desktop/icons/source.png` 的蓝色几何 A 应用图标，与当前产品保持一致。原图来源与设计说明见 [应用图标](../../desktop/icons/README.md)。

新截图使用独立、只读的演示数据服务，运行真实构建后的前端。账号、环境与代理配置均为虚构示例，未导入登录凭据或个人历史；图中登录和检测状态仅为界面示例。截图未修改界面元素或叠加效果。

## 保留的会话演示素材

- `agent-sessions-landscape.mp4`：30 秒，1920 × 1080，60 fps，H.264 / AAC，支持边加载边播放。
- `promo-cover.png`：既有视频封面，1920 × 1080。
- `conversation-dark.png`、`trajectory-dark.png`、`conversation-light.png`、`settings-dark.png`：早期会话功能的 2560 × 1440 演示截图。
- `logo.svg`：既有宣传素材使用的绿色图标，保留作历史素材；当前 README 使用蓝色 `logo.png`。

视频内容未重新制作。在线播放使用 GitHub 视频附件，可在[项目首页的视频区](../../README.md#会话功能视频)展开播放器；仓库保留同一份 MP4，供下载与离线查看。视频展示会话浏览、工具轨迹与上下文接力，账号和 Skill 管理以当前 README 为准。

旧视频和会话截图同样使用虚构演示记录。视频中的上下文接力是流程演示，目标 Agent 需要能访问同机文件。配乐由 XSXB-Band 工程制作；字体使用得意黑、Noto Sans SC 和 JetBrains Mono（SIL Open Font License），本目录不分发字体文件。

第三方 Agent 名称与图标用于标识对应来源或客户端；相关许可见 [来源图标许可](../../frontend/src/assets/agents/LICENSE) 与 [组件图标说明](../../frontend/src/assets/components/README.md)。部分界面样式的来源与许可见 [DeepSeek Harness MIT 许可](../../frontend/public/harness-license.txt)。

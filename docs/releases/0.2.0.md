## 改进

- 新增应用内更新：检查、下载、签名校验、安装并重启。安装前需停止账号环境，账号数据保留。
- Claude 运行保障只在访问环境中显示一次；账号列表去掉额外保障行，凭据保存状态改用钥匙图标。
- 修复首次继承登录状态后，会话因尚未建立组织目录而无法自动迁移的问题。
- 同一账号的常规显示偏好可自动继承，执行权限、环境变量、网络身份和开发者设置单独保留。
- 支持清单内定义的官方插件，修复部分语言服务插件导致 Claude App 启动被误拦截的问题。
- 空配置实例不会清理其他实例正在使用的网络分流。

旧版本尚无应用内更新入口，首次需要安装一次此版本。后续发布可在“设置 → 应用更新”中获取。

# Agent Sessions 0.2.1

## 中文

- 节点支持按优先级配置备用，备用也能继续挂备用，展开为 A → B → C 的回退顺序，自动拦截循环引用。
- 启动时依次检查节点；运行中可选择故障提醒，或连续三次连接失败后自动重启环境并回退。切换前核对候选出口和地区，保留登录与会话目录，不自动切回主节点。
- 网络设置展示回退链、当前使用的备用和“继续回退 / 切回主节点”操作。节点仍被用作备用时不能删除。
- 浏览器、Claude App、运行保障状态和后台用量查询跟随实际备用出口。同一绑定节点下的运行环境一起重启，避免出口不一致。
- 出口查询暂不可用但服务仍可连接时，仅提示核对；全部备用不可用时保持当前线路，不退到系统直连。

自动回退会中断当前响应或工具任务；登录状态及历史会话保留。短请求检测不能覆盖所有长连接故障，对话卡住时仍可手动回退。

## English

- Configure ordered backup nodes, including nested backups, with cycle detection and an explicit A → B → C fallback sequence.
- Check candidates at launch. During use, choose notifications or automatic fallback after three consecutive connection failures. Verify the candidate exit and country before restarting affected clients; retain login and session directories and stay on the chosen backup.
- View the expanded sequence and current backup, continue to the next candidate, or explicitly return to the primary. Referenced backup nodes are protected from deletion.
- Browser clients, Claude App, runtime protection and background usage queries follow the effective exit. Clients sharing the same configured route restart together.
- An unavailable exit lookup alone does not trigger automatic restarts when the service is reachable. Exhausted backups keep the current route and never fall back to a direct connection.

Automatic fallback interrupts active responses or tool tasks while retaining login and session data. Short probes cannot detect every streaming failure; manual fallback remains available.

# Claude App 账号间会话同步

从账号管理启动或切换 Claude App 账号时，自动同步全部本地 Code 会话。先等待上一个受管 App 退出并保存，再汇总来源、写入目标账号的会话目录，最后启动官方 App。切回已经运行的窗口只聚焦窗口；下一次启动时再同步。

## 使用与范围

- 来源包括所有已配置 App 环境及会话设置中的本机 Claude Code、桌面补充索引目录。CLI 会话也会创建官方 App 可读取的会话索引。
- 同步完整 JSONL 正文、同会话目录下的工具输出与子代理文件、对应文件历史。正文逐字节复制，保留消息、附件载荷和原字段值。
- 同一段历史后续新增的内容更新已有记录；两边分别续聊产生不兼容历史时，保留两个分支。同步副本记录来源，后续切换不会不断复制同一会话。
- 新导入的记录采用官方 App 的 `imported-staging` 格式。首次在 App 中继续时，沿用官方 App 自己的导入确认与恢复流程；后续请求使用当前目标账号。
- 新副本使用目标账号独立的原生会话 ID，通过来源映射识别同一段历史；原始正文中的字段与字节保持不变。
- 首次登录尚未生成账号及组织目录时，先完成官方登录、选择组织；再次启动时自动同步。在账号详情及启动检查中显示同步结果。
- Chat、Cowork、没有本地正文的云端记录及远程 SSH / WSL 环境会话不在此范围。没有正文或还在写入的记录显示为待同步，并保留具体原因。

同步为合并，不将一个账号的删除传播到其他账号。来源账号文件在本次同步中保持原样。目标文件需要更新时，旧字节保存在应用数据目录的 `claude-app/session-sync-backups/<profile-id>/<sha256>`；文件替换采用临时文件写完、落盘后改名。每个目标环境的 `agent-sessions-sync.json` 记录来源、原生 ID 和正文摘要，用于后续去重及分支识别。

## 格式依据与验证

本机 Claude App 4.29.0 的安装包中，Code 会话管理器使用 `claude-code-sessions/<account-uuid>/<organization-uuid>/local_<uuid>.json`。`registerExternalSession` 写入 `cliSessionId`、`cwd`、`originCwd`、标题、时间、`importedFrom` 与 `stagedTranscriptPath`；`confirmImportedSessionResume` 将暂存正文移动到当前账号 Code 配置下的 `projects/<cwd-slug>/<cli-id>.jsonl`，随后保存确认状态。本实现按该持久化格式写入，保留各环境独立的账号登录与设备配置。

隔离样本已验证全量导入、重复启动去重、CLI 索引补充、导入暂存正文读取、跨账号续写后同步回来、双向分支保留、附属文件复制、目标旧内容备份及首次登录待同步状态。

官方 App 内嵌 Code 2.1.309 另已使用本地模拟接口验证恢复：给复制的正文使用新的文件会话 ID，保留正文中的所有原始字段；恢复请求同时包含原用户消息、原助手回复和新问题，成功接收模拟接口回复。Code 2.1.220 也通过相同验证。该验证仅使用临时配置和模拟凭据。真实账号在官方窗口发起模型请求的跨账号续聊尚未执行。

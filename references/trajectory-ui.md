# Agent Sessions 本地会话查看器

## 运行与核验

从仓库目录执行 `npm ci`、`npm run build:ui`，再启动 `python3 scripts/trajectory_server.py --port 8765`。开发时另开 `npm run dev`，Vite 将 API 请求代理到 8765。服务只绑定 `127.0.0.1`；可用 `--source-path SOURCE=PATH` 指定注册目录（可重复），旧 `--codex-home` 等参数保持兼容；`--state-home` 指定应用整理设置目录。`--codex-only` 可仅运行原有 Codex 适配器。

地址使用 `?id=来源:实例:原生键&ref=事件引用`，原有 Codex `?id=会话UUID&ref=T003/C002` 深链接仍兼容。默认会话依次取 URL、`CODEX_THREAD_ID`、最近的本地会话。服务读 `sessions/`、`archived_sessions/` 和 `session_index.jsonl`，缓存由原有解析器增量维护。未写完的 JSONL 行等待完整换行后才显示。

如果浏览器空白，先核验服务地址，再查看会话格式警告；不要因此直接导出原始 rollout。服务没有远程请求、聊天发送或原始文件写入接口。

验证命令：

```bash
npm run build:ui
npm run check:size
```

默认不新增或修改测试文件；通过构建、来源读取、原版源码与实际界面操作验证。

## 交互与数据范围

轨迹导轨对照 DeepSeek Harness 官方 `ui-trajectory` 源码中的 `timeline.ts` 与 `TrajectoryTimeline.tsx`（核对版本 `639ed015397290b3745d163aafe02ffee4aa3f84`）：未选中“时长”使用 sequence 投影，每条记录占 `[index, index+1]` 区段，整体宽度按记录数分配；不是固定 8px 小点。聚合区段覆盖所代表的连续记录，圈选和跳转使用同一投影。选中“时长”使用日志实际保存的执行区间，压缩区间外的空闲；整段会话没有有效执行时长时回退到 sequence，并禁用时长按钮，避免把历史日期间隔误画成执行时间。未保存的时长显示“未记录”，不会推算或显示 NaN。

轮次分界、悬停蓝线和空白处定位最近记录也与该源码对齐。已支持 Shift＋滚轮和右键平移；双击取消圈选且保留缩放位置是本应用按用户要求保留的行为。DSH 记录有首 token 与请求计时的步骤展示双色区段与请求详情；各 Agent 日志未统一保存这些元数据，没有记录时不伪造模型计时。

侧栏按各 Agent 自己的项目分组。Codex 优先读取 `.codex-global-state.json` 的 `local-projects` 与 `thread-project-assignments`，保留项目的真实名称。同一目录属于多个项目时，按会话明确归属区分，不能凭目录猜项目。`projectless-thread-ids` 中的会话归入“未分配项目”；其余历史记录使用工作目录分组。只读取所需项目元数据，不修改 Codex 设置。项目列表覆盖全部本地记录，会话列表按项目分页加载，每页最多 100 条，默认展开当前项目。

会话置顶、显示名称、归档和项目映射通过本地 API 写入应用独立的 `view.json`，macOS 默认位于 `~/Library/Application Support/Agent Sessions/`。后台使用动态端口时也能复用设置；旧浏览器设置在首次读取时迁移，旧 Codex UUID 转换为统一来源键。归档可恢复，不改各 Agent 自身会话状态，也不删除源文件。

每个项目默认显示 5 条会话，其余通过“展开其余 N 个会话”加载；当前会话保留在默认列表中。会话直接从项目列表打开，顶部放置 Agent Sessions 名称，不再展示品牌图片或“选择会话”大按钮；搜索由项目标题旁的图标打开。侧栏收起后，标题栏提供重新展开入口。对话与轨迹分别保留已加载内容、搜索条件、详情和滚动位置，切换会话时重置。

对话页使用聊天气泡和 Markdown 助手正文，向上或向下滚动到边缘时自动加载相邻历史页，没有“加载更早/更多对话”按钮；向前补页时保留已加载记录和阅读位置。过程消息与工具调用集中折叠；点击可跳转到轨迹中的同一引用。用户消息中 Codex 附加的浏览器/附件包装投影为正文和“附带上下文与附件”入口；事件的原始内容与复制内容仍保留原文。这是展示层整理，不替换任何字段值。

旧记录未标记回答阶段时，已结束轮次最后一条可见助手消息单独显示为正文；忽略外部导入结束标记，进行中轮次和未加载完的末尾轮次不据此推断。此规则只影响展示，不改原始阶段或状态。代码块保留换行，提供语言标签和复制入口；代码与宽表格在块内横向滚动。展开分页消息时重新解析完整已展开 Markdown，避免跨页代码块或表格断开。

对话、工具输入输出和轨迹详情中的图片附件，以及已解析的 Markdown 图片，共用原图预览。点击缩略图后按原始比例适配窗口，遮罩、圆角和关闭按钮沿用 DSH ImageLightbox；点击遮罩、关闭按钮或按 Esc 退出，焦点回到原图片入口且不改变阅读位置。预览通过 body portal 避免被工具卡片或折叠容器裁剪，键盘 Tab 保持在预览中。链接内的 Markdown 图片保留链接动作。图片仍使用原有按会话和记录授权的本地读取接口，不增加外部加载或改写历史。

思考使用 DSH `MarkdownText` 的 compact 排版：灰色次级文字、紧凑段落和标题、继承文字颜色的代码与链接。轨迹概述和完整预览保留 2px 浅灰引用线、12px 折叠标题，思考固定为 13px/20px；对话中的思考按正文的次级字号设置显示。思考和回复分开呈现，折叠状态按记录区分；所有来源共用同一组件，不按 Agent 名称选择样式。

详情内容由各类型组件承担 14px 的横向留白：消息预览、子工具入口和独立附件列表都必须包含留白，已有代码、JSON 或思考容器的内部留白不重复叠加。长工具名在可用宽度内省略并提供完整标题；文件名、来源标签、说明和路径错误允许换行。代码与表格保留各自的横向滚动，不靠裁剪详情面板隐藏内容。

轨迹页复用统一消息引用，滚到列表上、下边缘时自动补齐相邻页，没有加载按钮；向前补页保留阅读位置，时间线跳转后的前后记录也可继续滚动查看。每条原生记录保留独立导轨引用，不再按 250 条抽样；绘图仅绘制视口区段，点击、搜索和圈选仍使用完整索引。搜索使不匹配的片段变淡。拖动时间线聚焦范围、滚轮缩放、Shift＋滚轮横向平移、按住右键拖动平移，双击仅取消圈选并保留当前缩放和横向位置。Shift 平移兼容浏览器转换后的横向滚轮信号；触控板横向滚动也可平移，保持当前缩放比例，并在轨迹首尾停止。圈选结束后按完整事件索引定位，自动加载目标页；小范围滚到中间记录，大范围滚到首条，保持详情选择不变。空范围提示没有记录，右键平移和取消拖动不触发定位；较晚返回的定位请求不能覆盖新的圈选。时长尺度使用完整事件时间边界，不依赖聚合采样。定位时自动展开目标所在的折叠轮次或工具调用。详情面板左侧边缘可拖动，双击恢复宽度。

Codex 使用现有有界解析器的可见记录范围。DSH 展示日志实际保存的用户、上下文、助手思考/正文/工具块、系统与工具定义变化、压缩摘要、请求与用量；Claude 展示其实际保存的正文、思考、工具块及图片。来源没有保存的字段保持缺失。消息兼容旧的 `user_message` / `agent_message` 与 Desktop `item_completed` 中的 `UserMessage` / `AgentMessage`。

每次轨迹请求最多 250 条，默认 150 条；事件正文每页 7000 字符。工具结果在详情与检索时按需读取，列表只返回摘要。轨迹搜索覆盖完整正文、参数与可验证的结果；DSH 还包含历史工具定义和内容块。媒体目前展示引用与来源，不自动请求远程图片/音频。

内部调用的参数元数据最多 2500 字符，超过时提示前往外层调用查看完整输入；结果仅在用户打开结果页或调用 evidence 时匹配，不预读。对于已验证的 Promise.all/allSettled 编号输出，按明确编号关联；对于明确的逐条 text(await tools...) 输出，验证文本块数量后按输出顺序关联。重复编号、缺失或截断的 JSON、未支持的控制流不按数量猜测，不将组合输出作为独立结果返回；提供组合调用入口。内部调用状态从匹配到的独立结果取得，读取前显示未读取。外层记录保留完整组合输出。工具状态沿用原解析器根据结果结构/标记推断；记录间隔只表示调用与结果时间戳之差，不等于工具内部执行时间。未记录的 Schema、模型首字时间等显示“未记录”。

## 加载与刷新

轨迹跳转与手动刷新优先于实时轮询，前台读取期间不启动后台刷新或自动补页；正在返回的版本检查也需重新核对加载状态。跳转时保留已有记录，目标页读取成功后再替换；相同版本仍允许恢复缺失的正文页。前台请求结束后解除自身的加载状态，读取失败或超过 30 秒时提示原因并允许重试。

首次读取只展示一个轨迹骨架与状态提示，不同时展示分页加载提示；已有记录刷新时保留正文并显示紧凑提示。补页只在实际加载方向提示，亮暗模式与减少动画设置沿用公共主题。跨页跳转在插入目标页后直接定位，同页定位仍按动画设置滚动，避免原生 WebView 在新页平滑滚动时留下空白。

## 滚动与阅读位置

对话、轨迹与实时执行输出使用统一的滚动位置管理。补历史页、图片加载或折叠内容改变高度时，保持首条可见记录在视口中的位置；应用负责补偿的区域关闭浏览器重复锚定。首次进入对话定位最新消息，向上滚动或使用向上阅读按键立即暂停跟随，重新滚到底部恢复跟随。隐藏视图不更新滚动位置，切换回来保留阅读位置。自动位置恢复不被当作用户滚动；可见的后续加载入口由独立观察按需补载。

侧栏、对话、轨迹、详情及设置各自在边缘停止传递滚动。折叠过程展开后，由过程列表统一负责纵向滚动，工具输入输出、终端及展开的 JSON 字符串不再叠加高度限制；列表到达边缘后可继续滚动对话。独立工具卡片保留输入输出的高度限制，展开字符串随所在区域滚动。Markdown 代码与宽表格保留横向滚动，纵向仍可继续阅读正文。详情中的长 JSON 字符串展开高度只随容器尺寸调整，不随滚动位置变化。详情实时刷新保留已显示内容与展开状态，菜单聚焦不把正文拉到原按钮的位置。较远的轨迹跳转直接定位，短距离定位与回到底部遵循动画设置及系统减少动态效果设置。

事件详情的页签与标题根据同一记录的输入首页生成，与当前读取的参数、结果、原始内容及页码分开保存。同一记录的页签切换、分页或读取失败不增减页签；输入首页按会话、引用和版本复用，实时版本更新时重新读取。没有独立关联结果的子工具仍保留参数与结果说明，不能因结果正文为空而移除参数页签。

轮次、工具调用或对话过程收起后，如果后续加载入口进入当前视图的可视区域，自动按页补载。新页加载完仍留有空白时继续补载，直到入口离开可视区域或没有更多记录，不依赖滚动事件。沿用阅读位置恢复，不自动展开已收起的内容；隐藏视图不补载，同一分页位置不会重复并发请求，失败后保留手动重试入口。

公共参数与结果展示先识别 JSON，再通过 JSON5 识别未加引号的属性名、单引号和尾逗号等静态对象写法，复用同一字段树、折叠与复制交互。来源仍返回原文，不改写历史；包含变量、函数调用、模板字符串、展开表达式、未完成内容或非有限数值的代码保留文本，不求值或推断运行时参数。“原始内容”始终按原文展示。JSON5 随应用本地打包，许可证保存在 `frontend/public/json5-license.txt`。

## 界面来源与版权

参考官方仓库 [deepseek-ai/deepseek-harness](https://github.com/deepseek-ai/deepseek-harness)，固定源码提交 `639ed015397290b3745d163aafe02ffee4aa3f84`。同时通过原生界面核对本机 `0.2.0-rc.2` 的对话页、轨迹工具栏与详情页签。

`frontend/src/styles/dsh/` 的主题变量、工具栏、导轨、表格与详情样式由以下 MIT 源文件适配，主要改动为 CSS 模块选择器改为普通选择器、工具栏/时间线类名前缀和字体变量合并，并移除本应用未使用的规则与变量；按职责拆分的导入顺序保留原级联顺序：

- `packages/client/ui-theme/src/styles/{base,design-platform,gradient-shadow-text}.css`
- `packages/client/ui-trajectory/src/client/{TrajectoryToolbar,TrajectoryTimeline,TrajectoryTable}.module.css`

界面使用独立的 Agent Sessions 文字标识，不展示 DeepSeek 的品牌 SVG。对话气泡尺寸及正文节奏参考 `ui-chat` 的 `MessageItem`、`AssistantMarkdown`、`ChatView`；应用外壳在 React 组件与 Tailwind 布局中实现，后台适配器在 `backend/agent_sessions/sources/` 中实现。版权声明保存在 `harness-license.txt`。

来源选择器使用独立的受控 `Select` 组件，样式参考同一提交的 `ui-primitives/src/{Menu,MenuSurface}.module.css` 和 `ui-permission-presets/src/client/PermissionSelect.module.css`。保留 DSH 的紧凑按钮、圆角菜单、悬停色和尾部勾选标记；菜单通过 HTML Popover 顶层显示，避免侧栏裁剪，不使用系统原生 `<select>` 外观。支持方向键、Home/End、输入首字母定位、Enter/空格确认、Esc 取消、Tab 离开和点击外部关闭。业务筛选继续调用原有来源接口。

`icons.svg` 复用 `ui-primitives/src/icons/index.tsx`、`shared-artwork.tsx` 与 `TrajectoryTable.tsx` 的原始 SVG。轮次/调用展开收起图标按原工具栏的方框加减图形绘制为 SVG。图标通过本地 SVG sprite 加载，无外部字体或 CDN。界面保留项目会话侧栏、对话、轨迹与事件详情，移除了底部输入框。

Markdown 分词使用本地随附的 Marked `17.0.5`（MIT），随 Vite 从 npm 依赖打包，许可证在 `frontend/public/marked-license.txt`。分词结果用 React 节点构建，不执行记录里的 HTML；原文保留在事件详情中。运行时无需外部 CDN。源码与 Markdown 代码块按需使用 Shiki `4.3.1` 的 JavaScript 正则引擎，仅打包明确使用的语言；颜色复用 DSH 亮暗色变量。Shiki 许可证保存在 `frontend/public/shiki-license.txt`。

## Antigravity 执行结果

桌面端与 CLI 在来源筛选、会话标签和设置中分开。导出的 PLANNER_RESPONSE 常没有调用 ID：仅当下一条 GENERIC 的完整 search_web 查询与唯一调用完全一致、步骤连续时，才归并为该调用的结果；有唯一原生 ID 时使用 ID。不同查询、多调用或只包含 503 错误的记录不能靠顺序配对，保留为“执行结果”。旧 `S/结果步骤` 深链接仍解析到已关联的调用，原文按需读取。

DSH 原生轨迹的对齐规则、修正与验证见 [dsh-parity.md](dsh-parity.md)。

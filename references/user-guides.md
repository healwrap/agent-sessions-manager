# 页面操作引导

侧边栏底部的问号打开「帮助与引导」。侧边栏收起时，入口在顶部操作区；启动页也保留同一入口。账号页不再重复显示引导提示与操作按钮。

帮助窗口默认显示两条资料链接、「演示操作」与「开始配置 / 继续配置」。单项演示与使用提示默认收起，使用紧凑折叠行。没有真实账号时也可以体验所有演示。

## 演示模式

「演示操作」直接在当前工作区展示示例账号、代理、环境和用量，不套外层弹窗。顶栏保留演示标记、场景选择、重新演示和退出入口；退出回到之前的页面。可以体验首次配置、代理配置、添加账号，以及浏览器 / Claude App 的登录与切号。表单预填示例值，检测、订阅读取、启动、登录与停止均返回模拟结果。

演示直接导入正式的 `AccountWorkspace` 及其子组件，不另存一份页面布局；只替换数据与存储。正式页面的组件、样式或布局更新会同步到演示。Tour 通过控件的 `data-guide` 标记定位，移动控件会重新计算位置；新增、删除操作或改变流程时，需要同步调整步骤定义。

演示复用真实页面和控件，数据保存在该页面的内存中；API 层只分发到模拟处理器，未实现的操作返回说明，不回退到真实接口。演示文档使用 `connect-src 'none'`、`form-action 'none'`，只允许本应用嵌入。演示的 localStorage / sessionStorage 使用独立内存对象；原生应用打开、剪贴板与资料链接也不会执行本机操作。重新演示、切换场景或退出后，示例修改清空，真实账号、代理和配置进度不变。

「开始配置 / 继续配置」仍是实际操作引导，沿用以下流程与启动门控。

## 使用流程

- **首次配置**：添加或选择代理，检测出口，保存账号与独立环境，打开环境并核对登录身份。
- **代理配置**：支持已有 HTTP / SOCKS 地址、订阅链接和 Clash 配置。缺少 Mihomo 时可以在创建弹窗中安装内核。检测未通过时保留当前步骤。
- **添加账号**：保存本地账号资料与环境绑定。完整配置流程默认带入刚检测的代理。
- **首次登录**：浏览器从账号入口启动后，在对应窗口完成邮件登录；点击「检查登录身份」核对实际邮箱。Claude App 使用现有邮件链接引导，并由用户在 App 窗口确认登录。
- **切换账号**：等待当前环境停止，选择另一个账号，打开它绑定的环境。保留登录数据，不执行网站退出登录。

可随时点击浮层右上角关闭或按 Escape 暂停。进度保存在当前界面的本地存储，刷新后保持暂停，由用户继续；仅记录流程、步骤、账号和代理的内部 ID，不保存邮箱、代理地址或登录链接。关闭引导不会取消正在执行的业务操作。

账号资料入口使用用户指定的 [Claude账号注册订阅防封指南](https://x.com/Rivoclass/status/2111754234320613717)，代理获取入口使用 [ZapIP 长期静态 IP](https://user.zapip.net/#/static-ip/long-term)。链接分别放在新增账号、新增代理表单与帮助中。

## 状态与组件

`GuidedTour` 封装 Driver.js 1.10.2，负责目标等待、遮罩、定位、滚动和原生 dialog 的浮层；内容通过 React portal 复用 DSH 的 Button / IconButton、颜色、圆角和主题变量。`GuideLink` 负责资料入口。两者均在公共组件目录导出，并在 `/?components=1` 开发预览中提供交互示例；预览也可打开完整的示例账号演示。

浮层在高亮动画结束后的下一帧按 React 内容重新定位，DOM 内容变化时也刷新位置，避免初始空内容的尺寸盖住目标按钮。已在开启动画、两条受管代理、1440 / 1280 / 1024 / 760px 窗口下检查目标命中并执行正常点击。

`AccountGuide` 将真实保存响应、代理报告和环境运行状态映射为步骤。填写、保存、启动与停止均调用原有操作；引导不自动跳过启动检查。代理结果必须来自当前保存的代理 ID 与地址，且 Claude 链路取得 IP 并通过检测；更改检测地址或链路会清除当前有效结果。该检测证明本次探针链路，不替代实际环境的启动门控与连接观测。

`GET /api/browser-login?account_id=...` 只使用已运行且属于该账号的浏览器控制连接，在 HTTPS Claude 页面中读取当前登录身份。邮箱不匹配、网站验证未完成、凭据无效和环境未就绪均不推进。以名字命名的账号取得邮箱后需要用户确认。App 登录确认保留为人工核对，不把浏览器身份当作 App 登录证明。

Driver.js 的 MIT 声明随静态资源保存在 `frontend/public/driver-license.txt`，安装包不依赖外部 CDN。

完成 TypeScript、前端构建、Python 编译和源码长度检查。使用编译后的真实界面及内存中的模拟接口验证保存、检测失败重试、代理绑定、邮箱不匹配、登录完成、切号、App 独立确认、暂停恢复、Escape、浅深色和最小桌面窗口；所有外部请求均被截获。登录身份读取另以临时运行时验证允许的 CDP 命令及异常分支。

演示模式另使用实际静态服务响应头与空的账号数据验收：完整配置、订阅读取、模拟浏览器 / App 登录、切号、重置、单项入口、列表调宽、资料链接、浅深色及 760×560 窗口中的表单操作。演示页面无真实 API 请求、无原生命令调用，持久存储及原账号数据保持不变；实际配置入口仍显示空表单。

这些验证不修改现有账号、代理、Keychain 或系统设置，也不代表重新登录过真实 Claude 账号。Windows 本次未做实机验收。
